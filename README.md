Реальные кейсы тестирования поиска
Ниже представлены результаты реального прогона тестов на сайте autozest.ru. Я не просто проверил «работает ли поиск», я проверил его на устойчивость к ошибкам пользователя и нашел реальный дефект.

Что проверено:

Позитивные сценарии: Поиск по словосочетаниям, частичным словам (от 3 до 5 букв). Все кейсы прошли успешно (Pass).
Негативные сценарии: Опечатки, слитный ввод слов, пустой поиск. Система корректно обрабатывает ошибки и дает подсказки пользователю.
Найденный дефект (самое важное):

BR-01 (TC-02): Выявлена критическая проблема UX. Поиск не срабатывает по клавише Enter при вводе слова «канистра», хотя должен. Поиск работает только через клик по подсказке.
Почему это важно: Пользователь ожидает, что поиск сработает по Enter. Из-за этого бага он может уйти с сайта, не найдя товар.
Доказательство: Баг задокументирован в файле docs/bugs-search.md с четкими шагами воспроизведения.
Ценность этого портфолио: Эти артефакты доказывают, что я умею не только писать тест-кейсы, но и находить реальные проблемы в продукте, отличать «ошибку пользователя» от «бага системы» и грамотно описывать дефекты для разработчиков.
