# Тест-кейсы для стенда The Internet

## TC-001: Проверка авторизации (Basic Auth)
**Предусловие:** Открыта страница Basic Auth.
**Шаги:**
1. Ввести логин: admin
2. Ввести пароль: admin
3. Нажать ОК.
**Ожидаемый результат:** Открывается страница с надписью "Congratulations! You must be logged in".

## TC-002: Проверка чекбоксов
**Предусловие:** Открыта страница Checkboxes.
**Шаги:**
1. Кликнуть по первому чекбоксу.
2. Кликнуть по нему же ещё раз.
**Ожидаемый результат:** При первом клике галочка появляется, при втором — исчезает.

## TC-003: Проверка выпадающего списка
**Предусловие:** Открыта страница Dropdown.
**Шаги:**
1. Кликнуть на выпадающий список.
2. Выбрать любой пункт (например, Option 1).
**Ожидаемый результат:** В списке отображается выбранный пункт.
