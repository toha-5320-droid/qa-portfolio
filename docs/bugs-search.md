# Баг-репорты: Функционал поиска autozest.ru

## BR-01: Поиск по точному слову «канистра» не работает при нажатии Enter

**Приоритет:** High
**Статус:** Open
**Окружение:** Яндекс Браузер, ПК, 1920x1080, 27.08.2026
**Исполнитель:** Антон

### Описание проблемы
При вводе точного слова «канистра» и попытке запустить поиск через клавишу Enter или кнопку «Найти», система выдает ошибку «Товар "канистра" не найден». Поиск срабатывает только при выборе подсказки из выпадающего списка («Найти по описанию канистра»).

### Шаги воспроизведения:
1. Открыть сайт autozest.ru.
2. В поле поиска ввести слово «канистра».
3. Нажать клавишу Enter или кликнуть по кнопке поиска.

### Фактический результат:
Появляется сообщение об ошибке: «Товар "канистра" не найден». Товары не отображаются.

### Ожидаемый результат:
Система должна отобразить список товаров, содержащих слово «канистра» в названии или описании, независимо от способа запуска поиска (Enter, кнопка или клик по подсказке).

### Влияние на пользователя:
Пользователь, который не знает о подсказках или привык нажимать Enter, уйдет с сайта, так как не сможет найти товар. Это прямые потери конверсии.
