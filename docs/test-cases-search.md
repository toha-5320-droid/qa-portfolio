# Тест-кейсы: Функционал поиска на сайте autozest.ru

**Проект:** Интернет-магазин автозапчастей autozest.ru
**Цель:** Проверка корректности работы поисковой строки при различных сценариях ввода.
**Окружение:** Яндекс Браузер, ПК, разрешение 1920x1080.
**Исполнитель:** Антон
**Дата тестирования:** 27.08.2026

## Позитивные сценарии

### TC-01: Поиск по сложносоставному наименованию
**Предусловия:** Сайт загружен, поле поиска очищено.
**Шаги:**
1. Кликнуть по полю ввода поиска.
2. Ввести запрос «масло промывочное».
3. Нажать кнопку поиска (или клавишу Enter).
**Ожидаемый результат:** Система отображает список товаров, соответствующих словосочетанию «масло промывочное».
**Фактический результат:** Без проблем находит товары по словосочетанию «масло промывочное».
**Статус:** Pass
**Приоритет:** High

---

### TC-02: Поиск по точному односложному наименованию (НАЙДЕН ДЕФЕКТ)
**Предусловия:** Сайт загружен, поле поиска очищено.
**Шаги:**
1. Кликнуть по полю ввода поиска.
2. Ввести запрос «канистра».
3. Нажать кнопку поиска (или клавишу Enter).
**Ожидаемый результат:** Система отображает список товаров с названием «канистра».
**Фактический результат:** По Enter/кнопке поиска выдает ошибку «Товар "канистра" не найден». Поиск срабатывает только при клике на подсказку «Найти по описанию канистра».
**Статус:** Fail
**Приоритет:** High
**Дефект:** BR-01

> **Комментарий тестировщика:** Функционал поиска работает некорректно при самостоятельном вводе слова. Пользователь вынужден использовать автодополнение, что ухудшает UX. Требуется исправление логики обработки запроса.

## Сложные сценарии (ошибки пользователя и мусорные данные)

### TC-06: Поиск слова с опечаткой
**Предусловия:** Сайт загружен, поле поиска очищено.
**Шаги:**
1. Кликнуть по полю ввода поиска.
2. Ввести слово с опечаткой (например, «каниистра»).
3. Нажать кнопку поиска.
**Ожидаемый результат:** Система предлагает варианты исправления или показывает товары, максимально близкие к запросу.
**Фактический результат:** Корректно выводит: «Товар "каниистра" не найден. Возможно, вы ввели неправильный номер».
**Статус:** Pass
**Приоритет:** Medium

### TC-07: Поиск без пробела между словами
**Предусловия:** Сайт загружен, поле поиска очищено.
**Шаги:**
1. Кликнуть по полю ввода поиска.
2. Ввести два слова слитно (например, «маслопромывочное»).
3. Нажать кнопку поиска.
**Ожидаемый результат:** Система находит товары по ключевым словам или показывает пустой результат с подсказкой.
**Фактический результат:** Информирует: «Товар "маслопромывочное" не найден. Возможно, вы ввели неправильный номер».
**Статус:** Pass
**Приоритет:** Medium

### TC-08: Поиск при пустом поле ввода
**Предусловия:** Сайт загружен, поле поиска очищено.
**Шаги:**
1. Кликнуть по полю ввода поиска.
2. Не вводя текста, нажать кнопку поиска.
**Ожидаемый результат:** Система не выполняет поиск или выводит сообщение «Введите запрос».
**Фактический результат:** Не дает искать, пока не введено слово. Валидация отработала штатно.
**Статус:** Pass
**Приоритет:** Low

### TC-09: Поиск несуществующего словосочетания
**Предусловия:** Сайт загружен, поле поиска очищено.
**Шаги:**
1. Кликнуть по полю ввода поиска.
2. Ввести заведомо несуществующее слово (например, «войлочные панели»).
3. Нажать кнопку поиска.
**Ожидаемый результат:** Система показывает пустой список и сообщение «Товары не найдены».
**Фактический результат:** Корректно информирует: «Товар "войлочные панели" не найден. Возможно, вы ввели неправильный номер».
**Статус:** Pass
**Приоритет:** Medium
