# Баг-репорты

## BUG-001: Зацикливание окна авторизации
**Статус:** Open
**Приоритет:** Medium
**Описание:** При вводе неверных данных окно авторизации появляется повторно, не давая пользователю легко закрыть диалог.
**Шаги воспроизведения:**
1. Открыть страницу Basic Auth.
2. Ввести неверный пароль (например, `wrong`).
3. Нажать ОК.
4. Попытаться закрыть окно или нажать «Назад».
**Фактический результат:** Окно запроса пароля появляется снова.
**Ожидаемый результат:** После 2–3 неудачных попыток окно должно закрыться, а пользователю показать страницу с ошибкой.
